To start the project:
    First start with backend part:
        1. open a terminal
        2. Enter inside of the path spanish_tutor_backend (cd spanish_tutor_backend)
        3. Activate virtual environment (./venv/Scripts/activate in Windows, python3 venv/bin/activate in Linux)
        4. Deploy the backend (uvicorn main:app --reload)

    Then deploy frontend:
        1. Open another terminal
        2. Enter inside of the path spanish-tutor-ui (cd spanish-tutor-ui)
        3. Run the frontend (npm run dev)
